\section{Artifact}

The release-facing artifact is rooted at \code{artifact_uncued_phase1/}. It includes the role-uncued pilot data, prompt artifacts, schemas, scorer files, model outputs, baselines, audits, examples, a minimal reproduction script, and an artifact verifier script. The manifest records 1022 hashed files and explicitly marks \code{cued_artifacts_included=false}.

The main verifier is:
\begin{quote}
\small
\code{uv run eha-verify-uncued-phase1}\\
\code{--artifact-dir ../artifact_uncued_phase1}\\
\code{--reports-dir ../reports}\\
\code{--out-dir ../reports}
\end{quote}

The Phase 17 readiness report passes all artifact gates: layout, manifest hashes, visible-file hidden-label scan, gold/scorer inclusion, prompt inclusion, leakage gate, baseline gate, human leakage gate, model-run completeness, scored-result completeness, scorer audit, and explicit status that the main Phase 1 path deferred schema ablation. The minimal no-dependency smoke check is \code{artifact_uncued_phase1/reproduce_minimal.sh}. The later Phase 1.1 schema-ablation outputs are reported separately under \code{reports/} and \code{eha-mvp/results/}; they are not folded into the Phase 1 artifact.

The older \code{artifact/} package is quarantined as cued/internal evidence and is not a source for the main results in this paper.
