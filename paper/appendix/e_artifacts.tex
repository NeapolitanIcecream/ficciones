\section{Artifact Map}
\label{app:artifacts}

We release a minimal reproducibility package containing the opaque tasks, prompts, scorer notes, baseline outputs, audit summaries, frontier outputs, and a runnable example. The package is rooted at \code{artifact/} and includes:

\begin{itemize}
    \raggedright
    \item Opaque tasks and labels: \code{artifact/data/tasks_opaque.jsonl}, \code{artifact/data/documents_opaque.jsonl}, and \code{artifact/data/gold_labels.jsonl}.
    \item Prompt contracts: \code{artifact/prompts/standard_answer.txt} and \code{artifact/prompts/epistemic_hygiene_instruction.txt}.
    \item Scorer notes and runnable example: \code{artifact/scorer/} and \code{artifact/reproduce_minimal.sh}.
    \item Human-audit browser launcher: \code{artifact/serve_human_audit_review.sh}.
    \item Human-audit finalization shortcut: \code{artifact/finalize_human_audit.sh}.
    \item Final pre-release verifier: \code{artifact/verify_step1_release.sh}.
    \item Opaque frontier outputs and provenance: \code{artifact/outputs/frontier_main_opaque_predictions.jsonl}, \code{artifact/outputs/frontier_main_opaque_scored.csv}, and copied run/report manifests for the opaque main run.
    \item No-API baselines: \code{artifact/baselines/}.
    \item Audit summaries and pilot audit materials: \code{artifact/audits/}, including the generated-lore schema ablation summary and sanitized row-level rows, the automatic active-verification action audit, the blank 50-row human-audit sheet with context, a wide worksheet for manual labeling, a model-blinded worksheet for manual labeling, local HTML review page, Markdown packet, model-blinded Markdown packet, reviewer brief, paper-update memo, audit protocol, audit manifest, human-audit attestation, validation report, and the Codex-assisted pilot audit.
    \item Package file manifest: \code{artifact/file_manifest.json}, which lists every packaged file except itself with byte size and SHA-256 hash.
\end{itemize}

The source result directories remain under \code{eha-mvp/results/}; the package copies the release-facing subset needed for a minimal independent check. We also maintain an executable readiness check:

The command is \code{uv run eha-step1-release step1-readiness-check}, with \code{--artifact-dir ../artifact}, \code{--paper-dir ../paper}, and \code{--out-dir ../reports}.

The check verifies required release files, the package file manifest's byte and SHA-256 hashes, the five no-API baselines, the four generated-lore schema variants, their three-model coverage, and the sanitized row-level coverage over 20 generated-lore tasks, active-verification human-audit validation, model-blinded worksheet importability, model-blinded audit packet coverage, human-audit attestation status, manifest consistency, opaque main-output provenance, copied frontier run/report manifests, and semantic-ID leakage over the release package. The active-verification audit manifest records the eight label fields used for the pilot audit: semantic usefulness, machine executability, exact target, required action type, contradiction-search need, primary-search need, trace-source need, and scorer strictness. The reviewer brief gives the human annotator a short route through the review surfaces, label fields, note requirement, Codex-triage separation, attestation, and finalization command. The model-blinded packet and worksheet omit model identity, prompt condition, and automatic scorer outcomes so an auditor can review action usefulness and executability with less provider or scorer anchoring. The paper-update memo gives the exact post-labeling counts and claim-boundary wording to use after validation, while preserving the separation between independent human labels and Codex-assisted triage. The human-audit attestation records the auditor identifier or role, completion date, review surface, independent-review confirmation, no-copy-from-Codex confirmation, all-50-row coverage, and completion of all eight binary labels plus notes; it is allowed to remain a template while the human audit is incomplete, but the readiness gate rejects unfilled fields once labels are complete. The finalization shortcut can import the wide worksheet with \code{--from-worksheet} or the model-blinded worksheet with \code{--from-model-blinded-worksheet}, run validation and finalization, rebuild the artifact package, and rerun the paper-aware readiness check after an independent human auditor has filled the labels and notes. The pre-release verifier runs the minimal example, test suite, paper build, readiness check, and git diff check before final release. In the current artifact package, the readiness report is intentionally \code{blocked} until the 50-row active-verification sheet is independently human-labeled and finalized. The Codex-assisted audit files are retained as triage artifacts and are not counted as human validation.
